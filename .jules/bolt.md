## 2025-01-20 - React `useDeferredValue` for Expensive Client-side Filtering
**Learning:** Client-side filtering of lists where properties (like descriptions and skill lists) are concatenated into a large searchable string can block the main thread and cause noticeable input lag in React during keystrokes, even when leveraging `useMemo`. `useDeferredValue` acts as a highly effective performance technique specifically in concurrent React (18+) to prioritize input state updates while deferring the heavy re-computation of the filtered list until after the input has updated, keeping typing snappy without needing a traditional debounce.
**Action:** When filtering long lists or performing expensive O(n) text matching on keystrokes in React applications, consider `useDeferredValue` for the search query to keep the UI input responsive before resorting to debouncing or full backend searching.
